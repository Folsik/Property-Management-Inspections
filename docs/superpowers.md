# Superpowers status

Upstream: https://github.com/obra/superpowers

**Current status: Not installed or activated in this chat's coding harness.** The repository does not vendor or submodule the framework. Following its methodology in documentation is not equivalent to installation.

To enable skills for this project, install **Superpowers** using the official plugin for your actual coding agent (e.g. Codex app Plugins → Coding → Superpowers → Install, or Codex CLI `/plugins`). Confirm the plugin is enabled and restart the agent session if the harness requires it.

Design/plan → test-first implementation → verification → review checkpoints are documented separately in docs/architecture.md. The Python / Go service is not dependent on this agent plugin.
